Privacy

Short version: your files never leave your device, there are no cookies, and the only thing we measure is how many people visit each page.

Your files

The sound generator, cover resizer and sprite slicer do all their work with JavaScript inside your browser tab. Images you open and sounds you make are never sent to any server, and we have no server that could receive them. Downloads are created locally and saved straight from your browser.

The sound generator puts its current settings in the page address (after the #) so you can copy a link to a sound. That part of the address isn't sent to servers when the page loads.

Page view counts

We use GoatCounter, an open-source analytics service, to count page views. It records the page path, the referring site, browser and OS type, screen size and an approximate country. It does not set cookies, does not track you across sites, and does not store your IP address. See GoatCounter's own privacy notes for details. If you block it with an ad blocker, every tool still works the same.

Hosting

The site is static files hosted on GitHub Pages. Like any web host, GitHub may keep standard server logs. See GitHub's privacy statement for what they keep.

Links out

Each tool links to our itch.io store page. If you follow that link, itch.io's own privacy policy applies there.
