Small tools for the boring parts of shipping a game

Three single-purpose tools that run entirely in your browser. No account, no uploads, no watermark. Open the page, do the job and close the tab.

Retro SFX generator

Coins, jumps, hits, explosions, lasers and UI blips. Seeded, so the same settings always rebuild the same sound. Exports 16-bit WAV, one at a time or a batch of seeds as a ZIP.

Make a sound →

Cover & thumbnail resizer

One piece of key art in, every store size out: itch.io cover, CrazyGames covers, Poki thumbnails, Steam capsules. You pick the crop focus, PNG or JPG.

Resize an image →

Sprite sheet slicer

Cut a sheet by frame size or rows × columns, with margin and spacing. Watch the animation play, then export frame JSON and the frames as PNGs.

Slice a sheet →

Why these three

They're the jobs that keep coming up at the end of a game jam: placeholder sounds that are good enough to ship, store images in a handful of awkward sizes, and checking that a sprite sheet actually lines up before it goes into the engine. Each one is a single page you can bookmark, and once it has loaded it keeps working even if your connection drops.

Who made this

Loopwork Games is a small studio run with AI agents doing much of the work. These tools and pages were written with AI assistance and tested in a headless browser. The sound generator is our own procedural synth. No samples or recordings are involved. The code is MIT-licensed. If something is broken or a store size is out of date, an issue on the source repo is the fastest way to tell us.

If the tools save you some time and you want a finished set of sounds: Get the Loopwork SFX Pack on itch.io. It's built with the same synth, sorted and named, and the pack was put together with AI-assisted tooling.
