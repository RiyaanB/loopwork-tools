About the JSON

  
The JSON lists each frame in reading order (left to right, top to bottom), with its pixel rectangle
    x, y, w, h, its grid cell col, row, and a duration in milliseconds
    taken from the preview speed. Most engines can build an animation from this with a few lines of code.
    Phaser, PixiJS and LÖVE quads all take x, y, w, h directly. In Godot, the rectangles
    map onto an AtlasTexture region.


  
Margin vs spacing

  
Margin is the empty border around the whole sheet. Spacing is the gap
    between neighbouring frames. Tools like Aseprite, TexturePacker and Tiled can add both, and if the grid
    overlay drifts further off the further right it goes, the spacing is probably wrong. Any frames that only
    partly fit at the right or bottom edge are left out.
