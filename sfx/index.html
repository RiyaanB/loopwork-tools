Pick a sound type, nudge the seed until it sounds right, then download a 16-bit WAV. The same type + seed + settings always gives the same file, so you can write the recipe down (or copy the link) and rebuild the sound later.

What each slider does

  • Seed picks one variation of the type: a slightly different base pitch and, for noisy types (hit, explosion, whoosh), a different noise pattern.
  • Pitch multiplies the base frequency. Below 1 sounds bigger and heavier, above 1 sounds smaller and brighter.
  • Length stretches the whole envelope. The shape stays the same, only the timing changes.
  • Peak level is where the loudest sample lands after normalizing. −1 dBFS leaves a little headroom. Pick something lower if you plan to stack sounds.
  • Noise mixes white noise into the tone. A little gives coins and lasers some grit. A lot turns a jump into something closer to a swish.

Using the files

Exports are mono, 44.1 kHz, 16-bit PCM WAV. Godot, Unity, GameMaker, Phaser, Defold, Bevy and plain <audio> all load that format directly. If file size matters on the web, convert to OGG/MP3 afterwards (for example ffmpeg -i coin.wav -q:a 4 coin.ogg).

How it works

Each sound is built one sample at a time from simple oscillators (sine and square), filtered noise and an amplitude envelope, in the style of the classic sfxr tools. The seeded random generator is the same Mersenne Twister Python uses, so with sliders at their defaults this page produces exactly the same samples as the Python script we use to build our own packs.
